
MR Earn & Connect

About the Project

MR Earn & Connect is a student-focused platform designed to help students connect with others, showcase their skills, discover opportunities, and gain practical experience.

This project represents my first year project devolepment experience,where I exploered how technology can be used to solve problems faced by students.

Objectives

* Help students create profiles and showcase their skills.
* Enable students to find suitable opportunities.
* Encourage collaboration and networking among students.
* Help students develop their skills and gain practical experience.

Key Features

* Student profiles
* Skill showcasing
* Opportunity discovery
* Student connections and collaboration

Technologies Used

* Python
* HTML
* CSS
* JavaScript
* Flask
* SQLite

Future Enhancements

* AI-based skill matching
* Personalized opportunity recommendations
* Additional features to improve student collaboration and networking

How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Install the required packages:

pip install -r requirements.txt

4. Run the application:

python app.py

5. Open the local URL displayed in the terminal in your web browser.
