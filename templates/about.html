University Innovation Ecosystem

MR EARN & CONNECT

“Find Opportunities. Connect Skills. Earn.”

Created for Malla Reddy Deemed to be University (MRDU), Tirupati to solve the fragmentation of student career opportunities, unlock skill-based micro-earnings, and build verified academic portfolios.

🏆 Core Philosophy

“Every student has skills. Every skill can create an opportunity.”

⚠️ The Problem

Students often have to search different places for jobs, internships, competitions, services, projects, and career opportunities. Furthermore, students possess valuable practical skills (record writing, formatting, typing, Python coding) but lack a transparent campus platform to monetize them.

💡 The Solution

MR EARN & CONNECT combines all these disparate domains into one cohesive student-focused ecosystem. Students create rich portfolios, list marketable skills as campus services, receive orders, and track transparent job compatibility in real time.

✨ The Unique Value

The continuous 8-step journey: Learn → Build Skills → Create Profile → Analyze Skills → Connect → Find Jobs / Internships → Apply → Offer Services → Earn → Build Portfolio → Grow.

Architectural Constraint

Strictly Explainable Logic (NO AI Black-Box)

As required by the project specifications, MR EARN & CONNECT explicitly avoids opaque AI models or black-box embeddings for job matching. Instead, the Skill Compatibility Analysis is calculated transparently using pure Python string and set comparison logic. Students and judges can examine the exact matched skills (✔) and missing skills to develop (⚠) without algorithmic bias.

🐍 Technology Stack

Backend

Python 3.14 + Flask Web Framework

Database

Relational SQLite3 (15 Tables)

Frontend

Semantic HTML5, CSS3, Vanilla JS

Security

Werkzeug Password Hashing & RBAC
